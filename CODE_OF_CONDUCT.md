# Code of Conduct

## Our Standards

This project welcomes practical bug reports, translation fixes, documentation improvements, and patch-builder contributions.

Expected behavior:

- Be respectful and specific.
- Keep discussions focused on this repository.
- Provide reproducible details for bugs when possible.
- Respect the project boundary around official game assets, generated full patch packages, credentials, and cracked content.

Unacceptable behavior:

- Harassment, insults, threats, or personal attacks.
- Posting private information without consent.
- Uploading official game resources, generated complete patch packages, credentials, cracked files, or other content this repository cannot accept.
- Repeatedly derailing issue or pull request discussions.

## Enforcement

Maintainers may edit, hide, lock, or remove comments and contributions that violate this code of conduct. Repeated or severe violations may result in blocking from the repository.

For sensitive reports, use GitHub private vulnerability reporting instead of a public issue:
