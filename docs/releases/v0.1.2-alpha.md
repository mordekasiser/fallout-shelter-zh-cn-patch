# v0.1.2-alpha

发布日期：2026-07-07

这是一个测试版维护发布，主要修复 Windows 环境下 Python 运行时探测过早失败的问题。

如果你运行 `生成汉化补丁.cmd` 时看到 “No suitable Python runtime found”，但系统里已经安装了 Python 3.13 或更新版本，请改用这个版本重新生成。

## 主要变化

- 一键生成脚本在 `py -3.11` 不可用时，会继续尝试 `py -3` 和 `python`。
- Python 启动器探测只接受真实可执行文件，避免函数或别名遮蔽 `py` / `python`。
- README 高级命令补充说明：普通用户优先用 `generate_patch.ps1 -GameDir`；直接运行底层 `tools.build_patch` 时，非默认安装目录需要同时传 `--bundle` 和 `--game-dir`。
- 补充 PowerShell 回归测试，覆盖精确 Python 候选失败后继续尝试后续候选的场景。

## 已知情况

- 当前已知会被跳过的旧 term：
  - `Theme_Name_NewVegasExterior`
  - `Theme_Name_NewVegasNightExterior`
  - `Theme_Name_UltraciteExterior`
- v2.4.1 新增文本目前可能仍保持原文，等漏翻内容积累多一些后再集中更新翻译表。
- 生成后的 `data.unity3d` 可能明显大于官方原文件，这是脚本重新保存 Unity 资源包并写入中文文本、字体和 UI 字体引用造成的。

## 用户提示

- 在本页 `Assets` 中下载 `Source code (zip)` 并解压后运行脚本。
- 如果自动查找游戏目录失败，优先运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\generate_patch.ps1 -GameDir "你的 Fallout Shelter 游戏目录"
```

- 如果脚本报错中断，请不要把失败输出覆盖到游戏目录。可以先用 Steam 验证游戏文件恢复原版，再反馈完整控制台输出、Windows 版本、游戏版本或 Steam build、游戏目录识别方式和复现步骤。
