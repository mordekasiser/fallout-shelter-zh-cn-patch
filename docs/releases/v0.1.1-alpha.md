# v0.1.1-alpha

发布日期：2026-06-25

这是一个测试版维护发布，主要把 `master` 上已经验证过的兼容性修复同步到 GitHub Release。

如果你之前下载的是 `v0.1.0-alpha`，并且在生成补丁时遇到 “translation table contains terms not found in the language source” 报错，请改用这个版本重新生成。

## 主要变化

- 普通双击生成入口现在会在发现旧翻译 term 不存在时继续生成，而不是直接中断。
- 生成过程中会明确提示当前游戏版本和翻译表存在差异，方便判断风险。
- 严格校验模式仍然保留，用于维护时检查翻译表和当前游戏资源是否完全一致。
- 修复了一键脚本中 Python 构建输出影响路径识别的问题。
- 补充了自动化测试、GitHub Actions CI 和维护记录。

## 已知情况

- 当前已知会被跳过的旧 term：
  - `Theme_Name_NewVegasExterior`
  - `Theme_Name_NewVegasNightExterior`
  - `Theme_Name_UltraciteExterior`
- v2.4.1 新增文本目前可能仍保持原文，后续更新翻译表时再补。
- 生成后的 `data.unity3d` 可能明显大于官方原文件。脚本会重新保存 Unity 资源包，并写入中文字体和相关 UI 字体引用；如果看到输出文件达到约 2.14GB，通常仍可以先按正常结果看待。判断补丁是否正常，主要看脚本有没有顺利结束，以及进游戏后中文是否能正常显示。

## 用户提示

- 如果本版本仍失败，请在 Issue 中贴完整控制台输出、Windows 版本、游戏版本或 Steam build、游戏目录识别方式和复现步骤。
- 如果脚本报错中断，请不要把失败输出覆盖到游戏目录。可以先用 Steam 验证游戏文件恢复原版，再反馈错误信息。
