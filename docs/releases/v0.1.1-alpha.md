# v0.1.1-alpha

发布日期：2026-06-25

这是一个测试版维护发布，用于把 `master` 上已经验证过的生成兼容性修复同步到 GitHub Release，避免用户继续下载 `v0.1.0-alpha` 旧包后遇到已修复的问题。

## 主要变化

- 普通双击生成入口现在允许跳过当前游戏资源中已经不存在的旧翻译 term，并在生成前和生成过程中显示风险提示。
- 严格校验能力保留，维护者仍可用严格模式检查翻译表和当前游戏资源是否完全一致。
- 修复 PowerShell 一键生成脚本中 Python 构建输出污染函数返回值的问题。
- 新增一键生成路径和底层构建逻辑的回归测试。
- 新增 GitHub Actions CI、项目治理文件、维护者流程和当前项目状态记录。

## 已知情况

- 当前已知会被跳过的旧 term：
  - `Theme_Name_NewVegasExterior`
  - `Theme_Name_NewVegasNightExterior`
  - `Theme_Name_UltraciteExterior`
- v2.4.1 新增文本目前可能仍保持原文，后续更新翻译表时再补。
- 生成后的 `data.unity3d` 可能明显大于官方原文件，主要原因是补丁会嵌入中文字体。

## 用户提示

- 如果你下载过 `v0.1.0-alpha` 并遇到 “translation table contains terms not found in the language source” 报错，请改用本版本或最新 `master` 重新生成。
- 如果本版本仍失败，请在 Issue 中贴完整控制台输出、Windows 版本、游戏版本或 Steam build、游戏目录识别方式和复现步骤。
- 不建议使用第三方附件里“强制忽略所有校验继续生成”的脚本；格式标记错误仍可能导致错位、显示异常或损坏输出。

## 验证

- 本地测试：`.\.venv\Scripts\python.exe -m pytest -q`
- Git diff 检查：`git diff --check`
- 发布后需要从 GitHub API 读回 Release 正文，确认中文没有乱码，标签指向当前发布提交。
